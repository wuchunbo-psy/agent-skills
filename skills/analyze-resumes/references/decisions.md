
## 视觉转录复用（2026-09-03 固化进 collect_and_extract.py）

- **规则**：BOSS 加密/扫描型 PDF 的既定流程是"脚本渲染→主会话视觉读→人工写回 JSON text"。重跑提取时，脚本检测到"本次提取不可读 + 现有 JSON 有非空 text"即判定为人工转录产物，复用并打 `text_source: vision` 标记，不再重复渲染（status 显示"复用视觉转录"）。本次可读则以本次为准。
- **why**：2026-09-02 曾华强案例——归档 peek 时主会话已读两页并转录，几小时后跑提取脚本不知道，又渲染一遍。当时靠"下次记得先写回再提取"（操作纪律）被用户否决：**约束要进脚本，不靠记忆**。
- **边界**：只救"提取不可读"的场景；文件内容更新后文本层可读了，新提取自然覆盖旧转录。
